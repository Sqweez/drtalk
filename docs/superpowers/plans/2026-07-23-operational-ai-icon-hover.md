# Operational AI Icon Hover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the four Operational AI cards visibly responsive on hover and keyboard focus, while preserving reduced-motion support.

**Architecture:** Add semantic classes and a keyboard-focusable container to the existing PHP card loop. Keep all visual behaviour in Tailwind source CSS: the card supplies a short transform/shadow transition and the icon receives a coordinated transform. The global reduced-motion rule remains the accessibility fallback.

**Tech Stack:** WordPress PHP templates, Tailwind CSS v4, POSIX shell checks, Prettier.

### Task 2: Add the accessible hover treatment

**Files:**
- Modify: `app/public/wp-content/themes/drtalk-redesign/front-page.php:164-173`
- Modify: `app/public/wp-content/themes/drtalk-redesign/src/input.css` inside `@layer components`
- Test: `app/public/wp-content/themes/drtalk-redesign/tests/verify-home-different.sh`

- [ ] **Step 1: Update the card markup**

Replace the existing article and icon classes with:

```php
<article class="operational-ai-card flex flex-col gap-8" tabindex="0">
	<img class="operational-ai-icon h-20 w-[7.875rem]" src="<?php echo $point_icon_url; ?>" width="126" height="80" alt="">
```

- [ ] **Step 2: Add the CSS component rules**

Add these rules in `@layer components`:

```css
  .operational-ai-card {
    border-radius: 1rem;
    outline: none;
    padding: 0.75rem;
    transition: transform 220ms ease, box-shadow 220ms ease, background-color 220ms ease;
  }

  .operational-ai-icon {
    transform-origin: center;
    transition: transform 220ms ease;
  }

  .operational-ai-card:hover,
  .operational-ai-card:focus-visible {
    background-color: rgba(243, 232, 247, 0.48);
    box-shadow: 0 14px 28px rgba(74, 30, 79, 0.12);
    transform: translateY(-0.5rem);
  }

  .operational-ai-card:hover .operational-ai-icon,
  .operational-ai-card:focus-visible .operational-ai-icon {
    transform: scale(1.08) rotate(-3deg);
  }
```

- [ ] **Step 3: Run the focused test to verify it passes**

Run: `sh tests/verify-home-different.sh`

Expected: `Different-section checks passed.`
